
You can modify properties of the engine inside the m_config.txt file. There you'll find fields to edits the resolution, window size, and fullscreen toggle.

```
resolutionWidth: 1600
resolutionHeight: 900
windowWidth: 1920
windowHeight: 1080
fullscreen: 1
volume: 1.0
```

This way you can have the engine run at a different resolution from the window size for example.
